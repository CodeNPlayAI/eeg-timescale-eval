# Public script inclusion audit — 2026-10-31

Scope: Only the reported IEEE Access experiments (self-EEG Core 3 with E1/E2/E3, OpenNeuro Core 3, WGAN-GP extension) and published figure/table production.

## Retained experiment paths

- `run_self_eeg_aligned_ddpm_20seeds.sh` → `scripts/run_aligned_ddpm_one_dataset.sh` → `scripts/generate_nmm_only.py`, `generate_diffusion_only.py`, `make_residual.py`, `make_add.py`, `evaluate.py`, `evaluate_cross_term_e2.py` → `src/common/*`; `scripts/aggregate_aligned_ddpm.py` aggregates seed outputs.
- `run_openneuro_aligned_ddpm_30subj_20seeds.sh` → `scripts/preprocess_openneuro_cli.py`, the same Core 3 runner, and `aggregate_aligned_ddpm.py`.
- `run_gan_only_30subj_macos_v2.sh` → `scripts/generate_gan_only.py`; `evaluate_gan_30subj_20seeds.py` calls `scripts/evaluate.py`.
- `run_table3_e2_v2.sh` reports E2 cross-term statistics. `reproducibility/run_table4_e3_v3.sh` processes original 20-seed E3 inputs; `reproducibility/run_self_eeg_wgan_evaluation_20260815.py` processes self-EEG WGAN evaluation.
- `reproducibility/build_revision_figures_tables_20260814.py` and `_table4_fixed_v3.py` provide report/table logic; `build_fig2_fig3_from_figure_data.py`, `build_fig4_from_table4_standalone.py`, `build_figure5_openneuro_winners.py`, `openneuro_figure5_core.py` and `build_figure6_selfeeg_four_generator.py` generate published figures from supplied curated inputs.

## Deleted before release

| Removed script | Reason |
|---|---|
| `scripts/analyze_rmax_control.py` | WGAN training diagnostic/holdout rmax tool, not invoked in final reported analysis. |
| `scripts/generate_diffusion_checkpoint_sensitivity.py` | Exploratory checkpoint sensitivity experiment, not in final paper experimental pipeline. |
| `scripts/run_ddpm_checkpoint_sensitivity.py` | Runner for non-reported checkpoint sensitivity experiment. |
| `scripts/make_stats_table_for_paper.py` | Legacy report-format conversion superseded by reproducibility paper table builders. |
| `scripts/plot_comparison_heatmap.py` | Generic historic plotting tool; paper figures use reproducibility/ builders. |
| `scripts/plot_psd_compare_4models_from_csv.py` | Optional per-seed PSD plot; final figures do not use this path. |
| `scripts/postprocess_compare_fig2_add_fixed.py` | Old per-seed comparison visualization superseded by published figure builders. |
| `scripts/stats_multiseed.py` | Legacy general multi-seed statistics; publication tables are generated by scoped builders. |
| `scripts/stats_multiseed_from_summary.py` | Old stats variant, not imported or invoked by final experiment/figure runner. |
| `scripts/aggregate_e2_cross_term_multiseed.py` | Unused alternate E2 aggregation implementation; canonical run_table3_e2_v2.sh retained. |

The old runner option `MAKE_FIGURES=1` previously invoked exploratory plotting scripts; it now explicitly errors rather than silently skipping or generating non-public figures. Default `MAKE_FIGURES=0` training/evaluation path is unchanged.

Figure 4 temporary validation CSV is written under ignored `outputs/validation/Figure4/`, not beside public figures. No raw EEG files or full training checkpoints are bundled. Curated inputs are sufficient for archived figure regeneration, not full retraining. **Scripts were audited for imports and command references; absence of references does not prove a file was never used historically.**

Only this derived public package is modified. Original Mac Studio project and prior candidate ZIPs remain untouched.
